画像・メディアの確認
====================

類似画像検索
------------

「類似画像を検索」で基準画像を選ぶと、選択した画像ルートから視覚的に似た
候補を検索します。EXIFの向き、ICCカラー、アルファを正規化し、知覚ハッシュで
候補を絞った後にブロック比較を行います。

比較表示
--------

左右比較、アルファ重ね合わせ、点滅、絶対差ヒートマップを切り替えられます。
表示用の正規化は元画像を変更しません。基準、類似、変形、切り抜き候補、
視覚的関連のラベルを確認してください。

安全上の意味
------------

視覚的一致は読み取り専用の証拠であり、完全一致へ自動昇格しません。黄色や
青の結果を「同じファイル」とみなして隔離することはできません。画像の選別や
整理目的のコピー／移動も、完全かつ最新のスキャンと受信ファイルの境界が必要です。
