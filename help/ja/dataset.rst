画像データセット整理
====================

データセット機能は、元画像とsidecarを一体で扱い、説明可能な保存対象の採点と、
類似画像がtrain／validation／testをまたがない分割計画を作成します。

準備
----

::

   dupeguru dataset prepare-root Incoming --destination-root Organized

既定では計画と検証を優先し、既存ファイルを暗黙に置換しません。受信ファイル、
保護ライブラリ、保存先の境界を明示してください。

注意
----

知覚的類似は、ラベルや意味が同じことを保証しません。分割リークの候補を減らす
ための根拠として使い、最終的なクラス、権利、品質、個人情報は別途確認してください。
