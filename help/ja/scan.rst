スキャン
========

モード
------

標準モードは一般ファイル、音楽モードはタグ、画像モードは画像を扱います。
画像モードでは「視覚的な類似」と「バイト単位の完全一致」を明示的に選べます。
スキャンの種類によって、ファイル名、フォルダー、タグ、内容、画像特徴など、
比較に使う証拠が変わります。

完全一致
--------

標準・音楽モードの「内容」と画像モードの「バイト単位の完全一致」では、まず
サイズで候補を絞り、候補だけに部分ハッシュ、必要に応じたサンプルハッシュ、
全体ハッシュを段階的に適用します。最後に安定したファイルハンドルからバイト
比較を行います。緑の完全一致グループだけが、実行直前の再検証を経て隔離対象に
なります。画像の完全一致スキャンは画素を復号しないため、視覚的な類似検索より
軽量です。

視覚的な類似
--------------

画像モードの「視覚的な類似」は、画像を復号して知覚特徴から候補を探します。
見た目が同じでもファイル全体のバイトが同じとは限らないため、結果は黄色または
青の確認専用です。完全一致の証拠へ自動昇格しません。

直接スキャン
------------

「内容」、ファイル名、フォルダー、タグ、画像の GUI スキャンは、選択した
ファイルシステムを直接探索します。読み取り不能、探索中の変更、キャンセル、
資源上限への到達がある場合、結果は不完全です。探索上限へ達した場合は部分的な
入力を照合せず、重複グループも公開しません。

大規模ライブラリ
----------------

GUI の「内容」と「バイト単位の完全一致」は軽量な直接スキャンであり、永続
カタログやスキャン履歴を作成しません。再開可能な履歴やカタログレポートが必要な
場合は、独立した ``dupeguru catalog`` CLI を明示的に使用してください。通常の
GUI スキャンで探索上限へ達する場合は、選択フォルダーを狭めるか除外条件を追加して
ください。
