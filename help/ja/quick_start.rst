クイックスタート
================

1. dupeGuru Neoを起動します。
2. 左下の「+」またはドラッグ＆ドロップで、調べたいフォルダーを追加します。
3. 各フォルダーを「受信ファイル」「保護ライブラリ」「比較のみ」「除外」の
   いずれかに設定します。
4. アプリケーションモードとスキャンの種類を選び、「スキャン」を押します。
5. 結果の根拠ラベルを確認し、残すファイルと候補を1グループずつ見直します。
6. 緑の「バイト検証済み完全一致」だけを選択し、
   「検証済みのマーク済みファイルを隔離」を実行します。
7. 残ったライブラリを確認するまで完全削除せず、問題があれば直前の隔離バッチを
   復元します。

.. image:: _static/main-window.png
   :alt: フォルダーを追加してスキャンする画面

黄色の類似結果、青の関連結果、灰色の未検証結果には削除権限がありません。
不完全なスキャンでも結果を確認できますが、一括ファイル操作は無効になります。
